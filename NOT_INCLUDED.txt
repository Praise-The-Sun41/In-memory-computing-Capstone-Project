Files not included in this repository
=====================================

To keep the repository small, the following were left out:

  * COMSOL model files (*.mph) — each 100 MB to 1.6 GB. They are regenerated
    by running the corresponding Java model scripts in COMSOL 6.x.
  * NumPy archives (*.npz, *.npy) and data files larger than 1 MB produced by
    the finite-volume and COMSOL runs. They are regenerated by the run
    scripts in the same folder.
  * Report-plotting scripts, notebooks and working notes that are not needed
    to reproduce the reported results.

All omitted files are available from the authors on request.
